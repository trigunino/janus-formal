
conjugation theorem gives

```text

G'_a = [F'_a F_a⁻¹, G_a] = -G_a H'_a G_a.
```

The frame connection is skew-adjoint and commutes with all five physical
projectors.


## 3. Relative heat traces and analytic continuation

For exact nuclear operator subtraction

```text
K_rel(a,t) = K_actual(a,t) - K_reference(a,t),
```

intrinsic trace additivity gives

```text
h_rel(a,t) = h_actual(a,t) - h_reference(a,t).
```

The Gamma-normalized Mellin transform is linear on the common convergence
half-plane.  A common open preconnected analytic domain containing zero and one
point of that half-plane forces, by the identity theorem,

```text
zeta_rel,a = zeta_actual,a - zeta_reference,a,
zeta'_rel,a(0)
  = zeta'_actual,a(0) - zeta'_reference,a(0),
T_rel(a) = T_actual(a) - T_reference(a).
```

Hence, once the standalone reference coefficient is known,

```text
T_actual = 0,
T_reference = -Tr(G_reference H'_reference)
```

imply

```text
T_rel = Tr(G_reference H'_reference).
```

This supplies the base and every local spectral-cut coefficient.

## 4. Intrinsic cyclicity

The new cyclicity layer treats a nuclear operator `T` and a bounded operator
`B`.  A common rank-one presentation of the two compositions uses

```text
B(rankOne x y) = rankOne (B x) y,
(rankOne x y)B = rankOne x (B† y).
```

Termwise,

```text
inner (B x) y = inner x (B† y).
```

Presentation independence therefore gives

```text
Tr(BT) = Tr(TB).
```

This is the reusable trace step needed to rotate bounded heat factors through a
nuclear Duhamel insertion before applying a semigroup identity.

## 5. Pointwise nuclear Duhamel variation

For a reference heat family, the operator identity is

```text
partial_a K_a(t) = (-t) • D_a(t).
```

Intrinsic scalar linearity of the nuclear trace gives

```text
partial_a Tr(K_a(t)) = -t Tr(D_a(t)).
```

On logarithmic weights satisfying `w(t)t = 1`,

```text
partial_a (w(t) Tr(K_a(t))) = -Tr(D_a(t)).
```

The short- and long-time weighted integrals each retain their own dominated
differentiation certificate.

## 6. Rank-one operator-valued regional integrals

For one time region, a common spectral index type is selected with
parameter-dependent vectors and time-dependent scalar coefficients:

```text
D_a(t)
  = sum_i coefficient(a,t,i) rankOne(left(a,i), right(a,i)).
```

The vectors are fixed with respect to heat time on the region.  Define

```text
integratedCoefficient(a,i)
  = integral_region coefficient(a,t,i) dt
```

and the integrated operator

```text
D_region,a
  = sum_i integratedCoefficient(a,i)
      rankOne(left(a,i), right(a,i)).
```

Nuclear-norm summability is recorded both pointwise and after integration.  One
explicit exchange theorem

```text
integral_region sum_i traceTerm(a,t,i) dt
  = sum_i integral_region traceTerm(a,t,i) dt
```

then forces

```text
integral_region Tr(D_a(t)) dt = Tr(D_region,a).
```

Thus neither the short-time nor the long-time trace-integration equality is a
free scalar field in the strongest frontend.

## 7. Short/long boundary matching

Let

```text
D_short,a = integral_short D_a(t) dt,
D_long,a  = integral_long  D_a(t) dt.
```

The global renormalized operator identity is split at the common temporal
boundary.  The short-time calculation produces a matching operator `B_a`:

```text
C_a - D_short,a = G_a H'_a + B_a.
```

The long-time primitive/decay calculation produces exactly the same operator:

```text
D_long,a = B_a.
```

Consequently,

```text
(C_a - D_short,a) - D_long,a = G_a H'_a.
```

Intrinsic trace subtraction, followed by transport through this operator
equality, gives

```text
C'_a
  - integral_short Tr(D_a(t)) dt
  - integral_long  Tr(D_a(t)) dt
    = Tr(G_a H'_a).
```

This scalar identity is now a theorem.
