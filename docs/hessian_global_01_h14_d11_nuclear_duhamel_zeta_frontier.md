## 1. H14 and the D11 unitary frame

The existing H14 closure supplies

```text
H_0 restricted to (ker H_0)ᗮ,
positive reduced gap c,
two-sided reduced Green G_0,
‖G_0‖ ≤ c⁻¹.
```

An operator-norm differentiable represented D11 unitary frame `F_a` satisfies

```text
H_a F_a = F_a H_0,
F_a P_s = P_s F_a,
F_0 = id.
```

It transports the exact H12 physical basis, the canonical orthogonal kernel
complement, the gap and the Green family.  In fixed coordinates,

```text
F_a⁻¹ H_red,a F_a = H_red,0,
F_a⁻¹ G_a F_a = G_0.
```

The fixed-coordinate derivatives vanish.  In moving coordinates,

```text
H'_a = [F'_a F_a⁻¹, H_a],
G'_a = [F'_a F_a⁻¹, G_a] = -G_a H'_a G_a.
```

The D11 connection is skew-adjoint and block diagonal for the five physical
projectors.

## 2. Actual heat and zeta family

A unitary nuclear heat family is given by

```text
K_a(t) = F_a K_0(t) F_a⁻¹.
```

Transport of rank-one nuclear presentations proves

```text
Tr(K_a(t)) = Tr(K_0(t)).
```

One H12 finite-part packet and one H12 Mellin continuation therefore generate

```text
FP_a = FP_0,
zeta'_actual,a(0) = zeta'_actual,0(0),
T_actual(a) = 0,
D_actual(a) = D_actual(0).
```

The actual zeta family and its zero coefficient are outputs.

## 3. Relative heat and analytic continuation

Exact nuclear subtraction

```text
K_rel(a,t) = K_actual(a,t) - K_reference(a,t)
```

and intrinsic trace additivity give

```text
h_rel(a,t) = h_actual(a,t) - h_reference(a,t).
```

Mellin linearity holds on the common convergence half-plane.  A common open
preconnected analytic domain containing zero and a seed point in that
half-plane gives, by analytic uniqueness,

```text
zeta_rel,a = zeta_actual,a - zeta_reference,a,
zeta'_rel,a(0)
  = zeta'_actual,a(0) - zeta'_reference,a(0),
T_rel(a) = T_actual(a) - T_reference(a).
```

Thus the reference coefficient determines every relative spectral-cut
coefficient.

## 4. Automatic intrinsic cyclicity

Given one nuclear expansion

```text
T = sum_i c_i rankOne(x_i,y_i)
```

and one bounded operator `B`, the implementation automatically constructs

```text
B T = sum_i c_i rankOne(B x_i,y_i),
T B = sum_i c_i rankOne(x_i,B† y_i).
```

The operator norm of `B` controls both nuclear-norm series.  Cauchy–Schwarz
controls the two trace series.  The original operator sum is mapped through the
continuous composition map, so the composition expansions are no longer
separate inputs.

Termwise,

```text
inner (B x_i) y_i = inner x_i (B† y_i).
```

Presentation independence gives

```text
Tr(BT) = Tr(TB).
```

## 5. Fully spectral Duhamel simplex average

For the probability parameter `s`, each Duhamel slice has a common spectral
frame

```text
D_a(t,s)
  = sum_i c(a,t,s,i) rankOne(x(a,t,i),y(a,t,i)).
```

The vectors are independent of `s`.  The averaged coefficients are

```text
c_avg(a,t,i) = integral_s c(a,t,s,i) dμ(s).
```

They form an intrinsic nuclear expansion of the genuine Duhamel operator.
One simplex sum/integral exchange proves

```text
Tr(D_a(t)) = integral_s Tr(D_a(t,s)) dμ(s).
```

This identity is therefore no longer a scalar field.

## 6. Cyclic semigroup collapse of every slice

Each slice is identified with

```text
K_left(a,t,s) (H'_a K_right(a,t,s)).
```

A nuclear expansion of `H'_a K_right` and bounded-composition cyclicity give

```text
Tr(K_left (H' K_right))
  = Tr((H' K_right) K_left).
```

Associativity and

```text
K_right(a,t,s) K_left(a,t,s) = K_full(a,t)
```

reduce every slice to

```text
Tr(H'_a K_full(a,t)).
```

Since `μ` is a probability measure, its average is the same trace.  Combining
this with the preceding section yields

```text
Tr(D_a(t)) = Tr(H'_a K_full(a,t)).
```

No scalar simplex-average or cyclic-collapse identity remains free.

## 7. Collapsed rank-one time integration

Only the simpler collapsed operator is expanded on each time region:

```text
H'_a K_a(t)
  = sum_i q(a,t,i) rankOne(u(a,i),v(a,i)).
```

Define

```text
q_region(a,i) = integral_region q(a,t,i) dt
```

and

```text
D_region,a
  = sum_i q_region(a,i) rankOne(u(a,i),v(a,i)).
```

Pointwise and integrated nuclear-norm summability are explicit obligations.
One sum/time-integral exchange per region gives

```text
integral_region Tr(D_a(t)) dt
  = integral_region Tr(H'_a K_a(t)) dt
  = Tr(D_region,a).
```

The averaged Duhamel operator itself does not need a time-region expansion.

## 8. Short-time endpoint limit

Let cutoff counterterms and cutoff short-time integrals converge separately:

```text
C_ε -> C,
D_short,ε -> D_short.
```

The renormalized remainder satisfies

```text
(C_ε - D_short,ε) - B -> G H'.
```

Continuity of subtraction gives a second limit of the same function,

```text
(C - D_short) - B.
```

Uniqueness of limits proves

```text
C - D_short = G H' + B.
```

The exact boundary identity is an output.

## 9. Long-time endpoint limit

For finite long-time cutoff `R`, an operator primitive satisfies

```text
D_partial(R) + terminalPrimitive(R) = B.
```

The two limits are

```text
D_partial(R) -> D_long,
terminalPrimitive(R) -> 0.
```

Uniqueness of limits gives

```text
D_long = B.
```

Again the exact boundary identity is not supplied.

## 10. Integrated Duhamel–Green trace identity

The common matching term cancels:

```text
(C - D_short) - D_long = G H'.
```

Intrinsic nuclear trace subtraction and transport through this operator
equality yield

```text
C'
  - integral_short Tr(D_a(t)) dt
  - integral_long  Tr(D_a(t)) dt
    = Tr(G_a H'_a).
```

The finite-part logarithm is assembled term by term from the counterterm,
short-time and long-time contributions.  Reality of
`zeta'_reference,a(0)` removes the imaginary connection component, forcing

```text
T_reference(a) = -Tr(G_a H'_a).
```

Analytic actual/reference subtraction then gives every relative coefficient.
