## 1. Concrete H14 and the D11 unitary frame

The existing H14 closure supplies the genuine basepoint data

```text

```

One operator-norm differentiable represented D11 unitary frame `F_a` gives

```text

F_a P_s = P_s F_a,
F_0 = id.
```

It transports the exact H12 physical basis, the canonical orthogonal kernel
complement, the gap and the Green family.  In fixed coordinates,

```text
F_a⁻¹ H_red,a F_a = H_red,0,
F_a⁻¹ G_a F_a = G_0.
```

The fixed-coordinate derivatives vanish.  In moving coordinates the generic
conjugation theorem gives

```text
H'_a = [F'_a F_a⁻¹, H_a],
G'_a = [F'_a F_a⁻¹, G_a] = -G_a H'_a G_a.
```

The frame connection is skew-adjoint and commutes with all five physical
projectors.



## 3. Relative heat traces and analytic continuation

For exact nuclear operator subtraction

```text
K_rel(a,t) = K_actual(a,t) - K_reference(a,t),
```

intrinsic trace additivity gives

```text
h_rel(a,t) = h_actual(a,t) - h_reference(a,t).
```

The Gamma-normalized Mellin transform is linear on the common convergence
half-plane.  A common open preconnected analytic domain containing zero and one
point of that half-plane forces, by the identity theorem,

```text
zeta_rel,a = zeta_actual,a - zeta_reference,a,
zeta'_rel,a(0)
  = zeta'_actual,a(0) - zeta'_reference,a(0),
T_rel(a) = T_actual(a) - T_reference(a).
```

Hence, once the standalone reference coefficient is known,

```text
T_actual = 0,
T_reference = -Tr(G_reference H'_reference)
```

imply

```text
T_rel = Tr(G_reference H'_reference).
```

This supplies the base and every local spectral-cut coefficient.

## 4. Standalone reference variation

A reference finite-part logarithm is decomposed into

```text
counterterm contribution
+ short-time weighted heat integral
+ long-time weighted heat integral.
```

Each integrated contribution has the form

```text
I(a) = ∫_R w(t) h(a,t) dt.
```

For a nuclear operator Duhamel identity

```text
∂_a K_a(t) = (-t) • D_a(t),
```

intrinsic trace scalar linearity gives

```text
∂_a h(a,t) = -t Tr(D_a(t)).
```

On logarithmic weights satisfying `w(t)t = 1`,

```text
∂_a (w(t)h(a,t)) = -Tr(D_a(t)).
```

After differentiating under the two time integrals, the finite-part derivative
is

```text
countertermDerivative(a)
  - ∫_short Tr(D_a(t)) dt
  - ∫_long  Tr(D_a(t)) dt.
```

The remaining integrated spectral identity identifies this expression with

```text
Tr(G_a H'_a).
```

Reality of `zeta'_a(0)` then removes an imaginary connection component and
forces

```text
T_reference(a) = -Tr(G_a H'_a).
```
